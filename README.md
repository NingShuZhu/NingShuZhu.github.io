# 个人主页

简约的 GitHub Pages 主页，只展示项目、技术博客和联系方式。使用纯 HTML 和 CSS，无需安装依赖或构建。

## 更新内容

编辑 `index.html`：

- 项目分为「基础算法练习」「算法的进阶应用」「非正经项目」，每类保留一个标为「待发布」的模板条目；技术博客也保留一个模板条目。复制对应列表中的 `li`，填写名称和一句话说明；发布后将名称的外层 `span` 替换为 `<a href="实际地址">名称</a>`，并移除「待发布」。

在 `styles.css` 中调整排版和颜色。页面无需 JavaScript，支持手机屏幕和键盘导航。

## 项目详情

CartPole Control 已加入「基础算法练习」，独立页面为 `projects/cartpole-control.html`。该项目的介绍、实验结果、页面专用样式以及 Demo / GitHub 占位均集中在此文件中。

- 添加 Demo：找到「Demo 与源码」，按 HTML 注释中的 `video` 模板替换占位区域，并填写实际视频路径。
- 添加源码链接：将 GitHub 待补充文字替换为实际仓库链接，文件中附有模板。
