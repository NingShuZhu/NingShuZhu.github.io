CartPole Control：动态规划、最优控制与强化学习

欠驱动系统，移动小车以保持摆杆直立。在课程提供的 Python 仿真与算法框架上，实践 DP、MPC / iLQR 和 (Tabular) Q-Learning，研究算法选择与参数调整如何影响控制表现。

所用算法

  • 动态规划（DP & Value Iteration）：将小车位置、速度、摆杆角度和角速度离散化，利用已知动力学离线求出控制策略；比较折扣因子和代价权重，并分析可恢复区域。
  • 最优控制（MPC / iLQR）：用 iLQR 优化连续控制序列，在 MPC 中根据当前状态反复规划；测试预测时域对稳定性的影响，并与预计算轨迹加状态反馈的闭环 iLQR 比较扰动恢复能力。
  • Tabular Q-Learning：通过仿真交互学习左右施力的策略；比较固定学习率、学习率衰减和探索率衰减，改善训练后期的波动。

实验结论

参数与训练

  • DP：较大的折扣因子使远期失败风险更明显；本实验中，位置和角度代价权重均取 0.01 比均取 0.1 更平衡。在零速度的价值函数切片中，约 ±8° 是较易恢复的角度范围。
  • MPC：测试 Horizon h = 1–100，最短 h = 8 可避免回合提前终止，h = 30–40 可使平均代价低于 0.01。更长的horizon改善了前瞻性，也增加了在线优化规模。
  • Q-Learning：固定学习率候选中，0.05 整体较好；将学习率设置为从 0.1 线性衰减至最低 0.00001 时，约 850 万训练时间步达到收敛。单独降低探索率能缓和部分波动，但训练后期仍会出现性能下降。

扰动恢复与模型变化

每 20 步施加随机外力时，所测试的闭环 iLQR 比 MPC 承受了更高的扰动阈值。 推测这是因为 iLQR 并非简单地开环执行预计算控制序列， 而是通过状态反馈项 Kₜ(xₜ − x̄ₜ) 实时修正控制输入， 使系统能够在受到扰动后向名义轨迹恢复。 因此，该结果仅反映本实验配置下两种控制器的表现， 不能直接得出 iLQR 的鲁棒性普遍优于 MPC 的结论。

将评估环境的摆杆长度从标称 0.5 调至 5，原有 DP 策略仍表现出一定容错能力，但平均累计代价随长度增加而上升，说明模型误差会带来性能退化。

从直立稳定到连续旋转

沿用 MPC，将目标改为角速度 8，并调整小车位置、速度与摆杆角速度的代价权重，实现了摆杆持续高速旋转，同时抑制小车漂移。实际角速度围绕目标值周期性波动，并非严格恒定。

结论

DP 将计算集中在离线策略求解，但受状态离散规模限制；MPC 能根据当前状态持续规划，预测时域和反馈配置直接影响表现；Q-Learning 可以通过交互获得有效策略，学习率调度对最终训练稳定性尤其关键。

连续旋转实验说明，调整控制目标和代价权重，就能复用同一优化框架生成不同运动。项目的主要收获是将控制任务转化为可求解、可训练和可评估的问题，并通过实验理解参数选择带来的取舍。

实验基于仿真环境与课程给定的框架。
